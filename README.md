# VGC · Poker Club

素描纸张风格的扑克牌网页游戏。Python 3.9+ 标准库服务端、SQLite 数据库、原生 JavaScript 前端，无需安装 npm 或 Python 依赖。

## 启动

```sh
./start.sh
```

浏览器打开 **http://localhost:4141**。默认仅监听 `127.0.0.1:4141`，适合 Cloudflare Tunnel 的本机源站。自定义监听地址或端口：`HOST=0.0.0.0 PORT=4141 ./start.sh`。

Cloudflare 的 Public hostname / Tunnel ingress 中，将域名指向 **http://localhost:4141** 即可。本项目同一端口同时提供网页和 API，不需要单独配置 WebSocket；客户端按约 850ms 同步牌桌状态。域名与 Tunnel 由你手动配置，未更改本机 Cloudflare 设置。

## 功能

- 游戏主菜单：创建房间、单人模式、设置；进入模式后选择玩法及 AI 类型，单人模式自动补齐 AI 并开局。
- 设置统一管理模型 API、玩家昵称与密码，修改密码撤销其他设备会话。
- 注册、登录、退出；随机盐与 PBKDF2-SHA256（600,000 轮）保存密码摘要，HttpOnly / SameSite 会话 Cookie；通过 HTTPS 登录时设置 Secure。
- 六位房间号创建与加入；只有注册玩家可以加入，房主控制开局、AI 席位与连续对局。创建时可选择邀请 AI 的人数与类型；准备室点击空座位也可邀请规则 AI 或模型 AI。
- 服务端判定合法牌型、回合、牌权、身份与胜负。玩家只能读取自己的手牌，其他玩家仅公开剩余张数、升变与亮牌信息。
- 刷新或重新登录后返回现有房间。离线玩家保持席位，对局中任何玩家可认输结束整局。
- 规则 AI 会估算剩余手牌的出牌手数、保留顺子/对子/炸弹，优先够用的跟牌，同队安全领先时让牌，对手临近出完时加强压制；急牌根据自身手牌、队伍与公开牌数选择赠牌和目标。决策不读取对方手牌点数。提供合法出牌提示。模型 AI 支持兼容 Chat Completions 的 HTTPS API，在设置里提供基础地址、模型 ID 与 API Key；模型从合法动作列表中选动作，无效输出或请求失败使用规则 AI。
- 账号积分、六档段位、排行榜、最近 20 场真人战绩。仅整桌真人的对局计分；含任何 AI 的房间全部玩家均不计分。SQL 结算事件防止重复计分。
- 简洁素描游戏界面，桌面与手机手牌自动换行，无需横向滑动。每人只展示自己的最近一手，整桌最新一手正常亮度，之前的略暗；相同花色点数的重复牌显示数量。
- 急牌赠送弹出目标玩家选择，公开显示赠送牌，赠牌后继续正常出牌。
- 桌面与手机响应式大厅、准备室与牌桌；选牌、普通与特殊出法、混子自动/逐张指定、急牌赠牌、协商撤回、猜拳、开局升变。

## 玩法

| 玩法 | 人数 | 牌数 | 胜负与规则 |
| --- | --- | --- | --- |
| 斗地主 | 3 | 54 | 叫分地主，任一农民出完即农民队胜 |
| 4A4A4 标准 2.4 | 4 | 110 | 对座组队；含勾、叉、点、压、死压、回、黑桃 A、升变、急牌和爆牌 |
| 4A4A4 三人 | 3 | 86 | 独立争先，保留标准特殊规则 |
| 4A4 基础 | 4 | 54 | 对座组队，三张起炸，勾叉与基础 4A4 |
| 标准 + Fieldlark DLC | 4 | 150 | 添加额外 40 张牌，包括 Delta 花色 |

房间可选择「回进阶版」「死压进阶版」；停用的“分”玩法不启用。

### 本实现对规则细节的约定

正常出牌及斗地主叫分按逆时针轮转（自己 → 右侧 → 对座 → 左侧），跳过已完成玩家；三人局为自己 → 右侧 → 左侧。特殊截牌和直接获得牌权按各自规则处理。4A4／4A4A4 四人局中，已出完者的最后一手无人能管时，自由牌权交给其仍在场的对家。每座展示本轮或上一轮的出牌；不出替换为「不出」，已出完者的牌在下一轮清除。AI 按 1号、2号、3号命名。

1. 四人按对座组队，队分从 3、4、5…K、A 映射下一局主牌，升级封顶 A。以 A 为主获胜后本轮结束，下轮两队归零并回到 3。
2. 四人局仅剩一对对家时直接结算，展示所有玩家剩余手牌。首位出完者所在队获胜；其对家出完后剩 1 人升 1 级、剩 2 人升 2 级、无人剩余不升级。败队不升级，两队分别累计级数，下一局使用胜队的主牌。三人独立计胜局，首位完成者胜，按其累计胜局循环决定下一局主牌。
3. 4A4 基础版与标准版仅一轮的第一局亮黑桃 3 定先手；无人亮牌时随机选择先手。多人亮牌时隐藏选择猜拳；平局重猜，有多名胜者时胜者继续猜拳。后续对局首位完成者先发、先出，他与逆时针下家各比其他两人多一张；仍有升变确认阶段。创建基础版或标准版房间时可勾选进贡，默认关闭；启用后，被抓玩家下一局发牌后进贡最大的非急牌：抓一人给首位完成者，抓两人由胜方两位各选一张；收贡者各返还任意一张给对应进贡者，再进入开局确认。
4. 主牌可按原始点数进入顺子、连对、飞机，序列比较按原始点数；单牌、对子仍按主牌大小。黑桃 A 允许作为普通 A 单出；作为混子只能在多张组合内使用，不能代替王；代急牌时选牌点击出牌，自动进入赠送目标选择，不能在普通组合中混入急牌。自动配牌枚举常见合法目标牌型；任意独立替代可以逐张指定。
5. 普通「回」要求两张单牌同花色；进阶版要求同牌型、同张数，主体各点数组的花色构成逐组相同，附件任意。王、2 和主不能作为双方主体，附件只需符合带牌规则；黑桃 A 按声明后的点数和花色判断。「回」后的普通牌仍按原基础牌型比较。本轮结束后才重置回的使用次数。
6. 死压进阶版四张牌必须与被死压的点数相同；可在死压者再次出牌前截获牌权。「压」、点 2/主、死压获得自由出牌机会。死压可优先于点截牌，点 2/主直接获得牌权，不能再压。
7. 急牌在自己的出牌回合使用，消耗自己并赠送一张非急牌，公开显示赠送牌的花色与点数；不占出牌次数，可连续使用急牌并继续正常出牌；用完手牌则转到下一位。只剩急牌自动排末名，多位这种玩家按触发顺序排在实际出完者之后。
8. 叉、勾、点、压、死压有优先响应机会，单人悬浮提示持续显示并自动标记可管的手牌，可改选合法普通牌跟牌，点不出放弃；仅跨回合优先管牌暂停等待，已顺次轮到真人时不暂停；多人同样提示并标记，保持正常轮转，尚无人后续出牌时直接出，有一人出牌时点出牌自动请求其收回，已有两名玩家出牌则失去旧手的优先协商机会。叉后只能用同点单牌勾；无人勾则叉牌者继续自由出牌。勾后可再叉再勾；无人再叉则勾牌者自由出牌。上家已出完时可抢先特殊出牌；原下一家刚出牌可申请协商，当前已完成两人时不能协商。协商锁住牌桌，同意后恢复上一手之前的状态，再执行请求者的特殊出牌。
9. 斗地主全部不叫时最后一位成为 1 分地主；不使用倍数、春天等额外积分项。真人斗地主每位胜方 +24、负方 −24；其他玩法 +20/−20，积分最低为 0。认输让所在队判负，三人模式其余玩家胜。
10. 王炸可由任意两张/三张/四张王牌组成。DLC 中超过十张的同点炸弹按张数继续增加，仍低于 4A4A4。

完整出牌规则也可在游戏内「玩法手册」阅读。

黑桃 A 的「逐张指定」可分别选择每张替代牌的点数与花色。回牌按替代后的点数、花色判断，出牌记录显示如 `A♠ → 5♥`；王、2 和当前主牌仍不能作为回牌或被回牌的主体。未指定花色的自动配牌保留黑桃，单张黑桃 A 仍只允许作为原本 A 使用。

## 传送带 · V0.9

单人或多人菜单选择「传送带」。开局牌库固定110张，沿用4A4A4标准牌型，不使用升变、进贡和爆牌。四人各自为战，每人独立记录等级；第一名升两级、第二名升一级，其他人不变。下一局使用第一名的主牌，升级最多到 A，需赢下 A 主牌局才结束一轮。局内打到只剩一人时结算，不按对家提前结束。每局按技能规定的“N选M”发牌和保留，没有首走者及下家的额外牌。

通常出牌、不出或禁手结束后发一张。前两次轮到自己时，出空仍补一张、不算走完；第三次起，手牌和展示区中的未出牌全清空才可走完。资源类印记不计入未出牌。传送带已出完者的最后一手无人管时，牌权交给逆时针下一位未走完的身份；规则 AI 将其余玩家视为对手。

| 技能组 | 技能 |
| --- | --- |
| 标准 | 转换、稳阵、跨级、守望、回收、净化、聚宝 |
| 突破 | 恩赐、藏拙、顺手牵羊、施压、烙印、拆解 |
| 重生 | 重铸·七音、重铸·万化、重铸·嗜血、重铸·至高强化、重铸·丰收 |
| 多多益善 | 替身、窃取、取舍、千变、如影随形、追猎、奉还 |
| 智谋 | 投骰、献祭、灵魂绑定、死斗、节流 |
| 终极力量 | 救赎之力、追击之力、平衡之力、阴影之力、禁锢之力、激励之力 |

每人开局前选择一个技能，允许重复；房主可禁用技能，DLC须在建房时启用。完整名称、选牌数和效果见[全技能说明](docs/VGC-传送带全技能说明.md)。

每张急牌独立计数：前三次不废弃使用后回牌堆底，第四次必须轮换并销毁，也可提前轮换。急牌只在自己的非禁手回合使用，不占普通出牌；弃牌效果至少留一张，弃最大牌对仅剩一张的目标无效。牌堆耗尽不自动回收，只有急牌轮换时将已出牌中的非急牌洗混后置于牌堆底。

比较值为J=11、Q=12、K=13、A=14、2=15、主牌=16、小王=17、大王=18。跨级、至高强化加点不跳过主牌原来的位置；主牌进顺子时仍按原点数。手牌同时显示印面和实际点数。

如影随形沿用四个真人座位与两个独立出牌区，开局14张平分为A/B各7张；五个身份依次行动，同一人的两个身份只占一个名次，共享个人等级。烙印从本手包含的花色中自选，凑两枚立即结算；嗜血开局获得一枚印记，结束行动不进行通常发牌，而是弃牌或补牌至印记数，补牌不再增加嗜血印记；灵魂绑定开局选择并持续生效，可在自己回合更换，只同步获得牌，不同步减牌。投骰可管普通炸弹，花色和带牌沿用上一手；判定牌不算真实出牌、不触发出牌技能。

技能名、规则AI、操作界面及录音均按V0.9同步。`conveyor.py`独立管理传送带状态，`conveyor_skills.py`管理说明，共通牌型复用`engine.py`。

## 本机统计后台

随游戏服务启动，访问 `http://localhost:4143/`。首次输入 `data/admin-token` 文件中的管理口令；该文件自动生成、权限为 600，不纳入 Git。后台仅监听 `127.0.0.1`，拒绝转发请求与非本机 Host，玩家账号不能登录。Cloudflare 继续只指向 4141，不要将管理端口接入 Tunnel。可用 `ADMIN_PORT=4143 sh start.sh` 调整管理端口。

统计包含北京时间日活/近 7 天/近 30 天活跃账号、注册与新增、在线人数、活跃和未结束牌局、各玩法单人/联机实时及累计开局、完成/中断、参与人次、平均完成时长，以及今日模型调用量、失败率和耗时。单人指一名真人，联机指两名及以上真人，可包含 AI；在线及活跃牌局按最近 60 秒的前台活动计算。不同规则变体分别统计。

数据持久化到原 SQLite 的 `usage_*` 表，日活按账号去重，前台轮询每分钟最多更新一次该账号的日活记录。统计从功能启用时开始；历史完成战绩单列，无法回填历史日活、开局、单人/联机类型或时长。服务重启会将未完成对局记为中断。后台不展示玩家身份、手牌或 API 密钥。

## 数据与运行

SQLite 文件：`data/poker.sqlite3`，自动创建，包含账号、会话、对局结果和积分事件。数据库与 API 密钥不会纳入 Git。备份可使用 SQLite backup API，避免只复制正在写入的数据库主文件。

房间和正在进行的手牌存储在服务器内存；**服务重启会结束未完成的房间**，账号、积分与已完成战绩仍保留。模型 API 密钥保存在当前账号与房间的服务器内存中，清除配置或服务重启后清除。设置中的 API 配置自动用于你创建的房间；不会返回密钥给浏览器。模型调用只发送该 AI 自己的手牌和公开局面，不发送其他玩家的手牌。

适用于本机持续运行并通过 Cloudflare Tunnel 暴露的单进程部署。不要同时启动多个实例共享实时房间；可以在系统进程管理器中启动 `start.sh` 并配置自动重启。

## 文件

- `server.py`：HTTP、账号与数据库、房间、结算、AI 调度与模型接口。
- `engine.py`：牌组、牌型、完整游戏状态与规则 AI。
- `public/`：网页界面、纸张与扑克牌样式。
- `tests/`：规则与 HTTP 集成测试。

出牌操作只需选牌并点击「出牌」，服务端根据当前牌面自动识别普通牌、勾、叉、点、压、死压及进阶；普通跟牌合法时优先普通出牌，否则尝试「回」。急牌自动进入赠送目标选择，已有一人后续出牌时自动发起协商，无单独协商入口。

4A4 基础版不允许任何带牌组合。4A4A4 标准版及三人版中，N 张同点牌（N ≥ 3）可带 1～N−2 个单位，单位按单牌或对子计数；单牌附件按实际张数计算，允许混合单牌、对子及更多同点牌。例如五带三可带一单加一对，六带四可带两单加一对或一单加三张同点牌；全部对子也可按张数跟单牌附件。附件不同于主组点数。相同主组张数、单位数和单位类型才可正常比大小。斗地主保持经典规则。其他在场玩家都不出后，牌权持有者可重新自由领出合法牌型；已出完者的牌权交给其仍在场的对家。

## 音乐与音效

设置 → 声音可分别调整音效、音乐、语音音量，并在当前浏览器保存。默认提供合成音效和预生成中文语音，通过 Web Audio 播放以兼容手机；未配置的特殊语音回退到系统朗读。音乐留待放入。菜单、对局、30% 手牌残局共三个音乐位置，后两首在同一时间点 crossfade。文件路径与替换方法见 [AUDIO.md](AUDIO.md)。

基础版顺子至少 3 张连续单牌、连对至少 2 对；2 和王不进入顺子、连对及飞机，主牌可按原始点数参与。

4A4A4 至少三张 4 和两张 A，4 多于 A；等级只计可凑齐的核心（A 数量 + 1 张 4），多余 4 不提高等级，例如 44444AA 与 444AA 同级。手牌重叠收拢，Enter 出牌（进贡阶段还牌），Esc 取消选牌；输入框与弹窗不触发出牌快捷键。斗地主 AI 获得自由牌权时优先寻找两手出完的顺子、连对等组合。

每次成功行动生成一次播报，连线且页面前台的真人完成声音播放后确认，才能推进下一次玩家或 AI 行动。后台及断线玩家不阻塞牌桌，静音类别跳过播放。

左键按住手牌后滑动可连续选择；从已选中的牌开始拖动则连续取消，同一次拖动重复经过一张牌不会反复切换。真人与 AI 同时具有勾、点、叉等优先响应时，AI 等真人选牌或放弃后才争抢；多人普通轮转保持原有流程。

### 托管

对局内手牌上方可开启或取消托管，单人和联机均支持。托管使用规则 AI，座位与手牌工具栏显示“托管中”；可在播报期间取消。托管保留注册玩家身份、队伍及房间原有积分规则，不使用个人模型 API。

联机牌局中，房主连续15秒没有心跳会自动托管；其他玩家轮到自己操作后等待满60秒，也会自动托管。播报时间不计入等待时间，行动或取消托管会重新计时。单人不会自动托管，需主动开启。多人优先响应另有全员可见的5秒窗口，超时仅放弃本次机会；单人不启用该倒计时。

### 匹配与观战

多人玩法卡片下显示当前可匹配房间数量，点击匹配加入该玩法有空位的房间。创建房间时可选择“仅房间号加入”或“允许匹配加入”，以及是否允许观战；默认仅房间号加入、关闭观战。已开局、满员、房主离线及单人房间不参与匹配。

输入允许观战的房间号后点击“观战”，可查看公开出牌和手牌数量，不能查看未公开手牌、操作牌局或参与积分结算。随时可退出观战。预留的特殊房间不参与匹配。
